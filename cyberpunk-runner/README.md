# NEON RUN — Multiplayer Cyberpunk Runner

Бесконечный 3D-раннер в стиле киберпанк с мультиплеером в реальном времени. Бегайте по крышам неонового мегаполиса, соревнуйтесь с другими игроками и станьте лидером дня.

## Технологии

- **Клиент:** Three.js (r160+), Vite, ES2022
- **Сервер:** Node.js 18+, Express, Socket.io
- **Рендеринг:** WebGL с постобработкой (Bloom, хроматическая аберрация, виньетка, ACES тонирование)
- **Процедурная генерация:** детерминированный алгоритм на основе дневного seed
- **Аудио:** Web Audio API (процедурная музыка)

## Быстрый старт

```bash
cd cyberpunk-runner
npm install
npm run dev
```

Откройте `http://localhost:5173` в браузере.

## Управление

| Действие | Клавиатура | Мобильные |
|---|---|---|
| Смена полосы | ← → / A D | Свайп влево/вправо |
| Прыжок | ↑ / W / Space | Свайп вверх |
| Скольжение | ↓ / S | Свайп вниз |
| Овердрайв | Shift | Тап |

## Архитектура

```
cyberpunk-runner/
├── client/
│   ├── core/        # Игровой цикл, персонаж, коллизии
│   ├── level/       # Процедурная генерация мира
│   ├── network/     # Socket.io клиент, синхронизация
│   ├── ui/          # HUD, меню, лидерборд
│   ├── audio/       # Звуковой менеджер
│   └── rendering/   # Three.js сцена, постобработка
├── server/          # Express + Socket.io сервер
├── shared/          # Общие константы и утилиты
└── public/          # Статические ресурсы
```

## Мультиплеер

- Подключение в любой момент к общей комнате
- Другие игроки отображаются как полупрозрачные «призраки»
- Импульс стаи (3+ игрока рядом → бонус к скорости)
- Групповые контракты каждые 10 минут
- Мега-события каждые 3 часа
- Таблица лидеров дня

## Сборка для продакшена

```bash
npm run build
npm start
```
